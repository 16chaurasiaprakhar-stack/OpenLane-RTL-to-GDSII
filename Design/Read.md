# Design Folder

The `Design` folder contains all the project-specific files required to execute the OpenLane RTL-to-GDSII physical design flow. It serves as the primary workspace for the design, including RTL sources, OpenLane configuration files, timing constraints, pin configuration, execution results, and physical layout outputs.

## Folder Structure

```
Design/
├── src/                 # RTL source files
├── runs/                # OpenLane execution outputs
├── config.json          # OpenLane design configuration
├── pin_order.cfg        # I/O pin placement configuration
└── top.sdc              # Timing constraints (Synopsys Design Constraints)
```

### File Description

#### `src/`
Contains the Verilog RTL source files that define the digital design. These files are used as the input for synthesis and subsequent physical design stages.

#### `config.json`
The primary OpenLane configuration file that specifies the top module, design directory, clock settings, synthesis options, floorplanning parameters, placement, routing, and signoff configurations.

#### `pin_order.cfg`
Defines the order and placement of the input and output pins around the chip boundary, ensuring a consistent I/O arrangement during floorplanning.

#### `top.sdc`
Contains the Synopsys Design Constraints (SDC) used during synthesis and static timing analysis. It specifies:
- Clock definition
- Clock period
- Input delay constraints
- Output delay constraints
- Clock uncertainty
- Clock transition
- False path constraints

These constraints guide OpenSTA and the physical implementation flow to meet timing requirements.

#### `runs/`
Stores all files generated during the OpenLane execution, including reports, logs, intermediate databases, and final physical design outputs.

### Power Analysis

Post-route power analysis was performed to estimate the overall power consumption of the implemented design.

#### Power Summary

| Component | Power |
|-----------|-------|
| Internal Power | 14.2 mW |
| Switching Power | 6.81 mW |
| Leakage Power | 91.2 nW |
| Total Power | 21.0 mW |

The report indicates that internal power contributes the largest portion of total power consumption, while leakage power remains negligible.
